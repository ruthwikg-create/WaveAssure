# WaveAssure

**Physiological signal assurance workbench — research and education only.**

> This software is not a medical device and is not suitable for diagnosis, treatment, patient monitoring, clinical alarm handling, or deployment in hospitals.

## Current development status

The v0.9.0 research release has an offline Python/FastAPI backend, a local browser interface, physiological waveform analysis, WFDB import, retrospective reviewer tools, deterministic fault injection, research-only model training scripts and software test fixtures.

**No genuine VT classifier model is shipped; independent clinical performance has not been established.** Medical-device certification, ethical approvals and hospital authorization have not been obtained.

## Repository import status

This repository currently contains protective source-publication documentation. The full v0.9.0 source bundle must still be synchronized from the verified local ZIP; do not treat this repository as a deployable software release until its application, tests and dependencies have been uploaded and checked.

Do not commit waveform datasets, patient records, local databases, trained model artifacts, credentials or environment secrets.

See SECURITY.md for responsible use and limitations.
