# Data and model rights

**Code distribution:** original WaveAssure code is under the repository MIT license. Please review before any commercial redistribution.

**Clinical data:** the VTaC dataset is distributed separately by PhysioNet under **CC BY-SA 4.0**, with its own attribution, redistribution and share-alike conditions. The software license **does not** relicense PhysioNet recordings. No `.hea`, `.dat`, label CSVs or model weights trained on that data are bundled in this release.

**Scientific citation:** cite the data authors and DOI: VTaC v1.1 doi:10.13026/jg2e-tf67, plus the original NeurIPS paper. Distinguish v1.0/v1.1 waveform sources and avoid stating an unverified dataset version.

**Ethics:** PhysioNet describes existing research approvals and de-identification for its dataset. This does not authorize unrelated clinical data collection, hospital deployment, redistribution of protected health information, or a prospective patient study.

Official data documentation: https://physionet.org/content/vtac/1.1/
