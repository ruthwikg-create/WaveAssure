# WaveAssure interface design (v0.12)
A deliberate engineering layout for choosing recordings, inspecting traces, and documenting evidence.
- System UI fonts and local monospace for numbers; no downloaded fonts.
- Borders, stable panels, 6–8px corners, no glows, shimmering surfaces or animated medical waveforms.
- Light/Dark/System support remains; decorative motion defaults off for new sessions, optional 140ms hover response.
- Compact nav uses explicit accessible labels. The review interface shares the same tokens.
- **Presentation only.** Clinical model remains untrained, and clinical/regulatory approvals have not been obtained.
Validation on the owner's actual Windows laptop and assistive technology remain open.
